### 🧬 7-Pillar Sovereign Architecture & Post-Training Lifecycle

Rather than simple prompt-tuning, the Vigyan AI models were engineered through an institutional multi-stage post-training lifecycle:

```
[Standard Base SLM]
       │
       ▼  1. Depth Up-Scaling (DUS)
[22-Layer Spliced Architecture]  -->  (Interface Discontinuity / Layer Seam Shock)
       │
       ▼  2. Continual Pre-Training (CPT) Seam Healing (2,400+ Parquet Shards)
[CPT-Healed Manifold: shreyansh-1B-SLM-pretrain-stem-english]
       │
       ▼  3. All-Module Linear SFT (7 Projections, Dynamic Early-Stop @ Loss 0.1335)
[Cured Historical 0.048 Collapse --> Generalizing STEM Foundation]
       │
       ├──────────────────────────────────────────┐
       ▼  4. GRPO Policy Gradient RL              ▼  5. DPO Preference Alignment
[vigyan-2b-reasoning-grpo]                 [Vigyan-7B-STEM-DPO-v1]
(Autonomous <think> Reasoning Steps)       (Deterministic Calculus & Circuits)
       │                                          │
       └────────────────────┬─────────────────────┘
                            ▼  6. Sparse MoE Upcycling (Top-1 / Top-8)
       [Vigyan 1.5B 4x-MoE & Vigyan OLMoE 1B-7B (64 Experts)]
                            │
                            ▼  7. Sovereign Edge Delivery (Q4_K_M GGUF + SymPy AST)
       [Vigyan-Models-GGUF & C++ KùzuDB GraphRAG Engine]
```

1. **Depth Up-Scaling (DUS):** Spliced intermediate transformer layers expanding depth to 22 layers without retraining from scratch.
2. **Continual Pre-Training (CPT) Seam Healing:** Pre-trained over 13.14 GB of raw STEM literature (`shreyansh-1B-SLM-pretrain-stem-english`) to re-align query-key subspaces across spliced layer boundaries.
3. **All-Module Linear SFT:** Full-projection targeting (`q, k, v, o, gate, up, down`) with dynamic early-stopping at loss 0.1335, averting representation collapse.
4. **Group Relative Policy Optimization (GRPO):** DeepSeek-R1 style reinforcement learning eliciting self-directed step-by-step reasoning tokens (`<think>`).
5. **Direct Preference Optimization (DPO):** Preference modeling for verifiable physics and calculus derivations.
6. **Sparse MoE Upcycling:** Top-1 (1.5B) and Top-8 (7B) routing with contrasting negative prompt router calibration.
7. **Sovereign Edge Delivery:** Standalone Q4_K_M quantizations in `Vigyan-Models-GGUF` paired with exact SymPy AST symbolic engines (+162.5% accuracy gain over unassisted baselines).
